# NextStep Team AI Usage Log

This document records team level AI use for the NextStep project. It is based on
the GitHub repository history and on the team's disclosure of AI tool use. The
source repository is:

`https://github.com/ypengzhuoireland-sudo/NextStep`

## Evidence Boundary

GitHub commits and meeting minutes show what the team worked on each week. They
do not show every prompt or every private AI interaction by each member. For
this reason, this log does not claim that a specific commit, feature, or file
was generated by AI unless there is direct evidence. It separates visible
repository work from AI use disclosure.

The repository does contain product AI functionality, including hint generation,
assistant intent classification, recommendation explanations, and learning
advice. This is different from AI tools used during development.

## Tools Covered

- ChatGPT
- Codex
- Other AI assisted coding or writing tools, if used by team members

## Review Policy

- AI output was treated as draft support, not final project work.
- Code, design choices, documentation, and report text remained under team
  control.
- Backend and frontend changes were checked through GitHub review, local
  testing, FastAPI documentation, manual requests, or available tests.
- Evaluation claims and final conclusions were written and checked by the team.

## Product AI Functionality

The product can call an OpenAI compatible provider for progressive hints,
assistant intent classification, recommendation explanations, and learning
advice. These features are optional support layers. If the provider is
unavailable or returns an invalid response, the system uses deterministic
fallback hints, intent rules, and explanation templates.
